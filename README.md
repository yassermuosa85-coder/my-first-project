# my-first-project

صفحة HTML تجريبية بسيطة للبدء في تطوير الويب.

## المحتويات

- `index.html` — الصفحة الرئيسية
- `style.css` — التنسيقات
- `script.js` — منطق بسيط (عداد تفاعلي)

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو استخدم أي خادم محلي بسيط مثل:

```bash
python3 -m http.server
```

ثم افتح `http://localhost:8000` في المتصفح.
